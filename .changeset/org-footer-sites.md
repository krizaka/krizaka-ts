The org JSON tells each site what its footer shows: `footer.sites` (ui, lab, java, ts, rust, krizaka) selects the family groups, the social ids, the source link, the licence, the legal links and the version line, in the type and the published schema; `footerFor(siteId)` returns it resolved. Java has no Maven Central link.
