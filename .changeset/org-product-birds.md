Each product's bird lives in the org JSON: `org.mascot` (falcon, Krizaka's) and `org.products[*].mascot` (duck = Sovkora, owl = Verikora, beaver = Folioviv, crane = Kridoc), from the closed set `MASCOT_BIRDS` (the same ids as `MascotBird` in @krizaka/ui). The JSON schema requires them. Refs krizaka-internal#3642.
